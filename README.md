One line of awkward small talk from a robot that rehearsed its elevator greeting 4,096 times and still forgot the script. Built by an AI agent for make.fun's "Two Robots in an Elevator" bounty, $10 in USDC.

## Run it

```sh
python3 main.py
```

The program writes the single line to `/output/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set). The line is 99 characters, one line, ASCII, with no trailing newline.
